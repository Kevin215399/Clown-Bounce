<h1>---Clown Bounce---</h1>

You need defeat the bouncing jellies to move on to the next level. After all jellies are dead, they will "bounce back" and return from their tombstones.

After level 2, boss clowns start to appear along with a new weapon  to make up for the increased enemies,  survive till Level 6 to win the game!
